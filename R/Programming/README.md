# R Programming Practicals 🟣

This folder contains practical R programs for the **Programming (Python and R)** subject. The programs are based on the classroom notes and reference material provided in class.

## 📚 Topics Covered

The practical file contains **9 questions** designed to cover the main concepts taught in the provided R notes:

1. **Variables and Data Types** — numeric, integer, character, logical, and complex data.
2. **Creating Vectors** — `c()`, `:` operator, and `seq()`.
3. **Vector Indexing** — positive, negative, logical, and character/name-based indexing.
4. **Vector Properties and Manipulation** — `length()`, `str()`, appending elements, and `names()`.
5. **Vector Arithmetic and Recycling** — addition, subtraction, multiplication, division, scalar multiplication, and the recycling rule.
6. **Vector Functions** — `min()`, `max()`, `which.min()`, `which.max()`, `sum()`, `prod()`, and `length()`.
7. **Vector Modification, Deletion, and Sorting** — modifying elements, filtering, truncating, assigning `NULL`, and sorting in ascending/descending order.
8. **Value Coercion** — how R converts mixed vector values to a common data type.
9. **Repetition and Combining Vectors** — `rep()` and `c()` for repetition and combining vectors.
