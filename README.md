## 🧮 R Statistics Practicals

The R section contains practical programs related to probability, distributions, and sampling.

### Topics currently covered

- **Sampling** — population creation, random sampling, and sample mean
- **Binomial Distribution** — exact, cumulative, and complementary probabilities, plus random observations
- **Poisson Distribution** — customer, call-center, and hospital arrival probability problems
- **Chi-Square Distribution** — density, cumulative probabilities, interval probabilities, critical values, random observations, and histogram

R programs are written primarily using the standard distribution functions such as `dbinom()`, `pbinom()`, `dpois()`, `ppois()`, `dchisq()`, `pchisq()`, `qchisq()`, and `rchisq()`.

## MATLAB Practicals

The MATLAB section contains numerical and matrix-oriented practical work covered in class.

### Topics currently covered

- **Dot Product** using a `for` loop
- **SAXPY** operation using a `for` loop
- **SAXPY** with randomly generated values using `randi()`
- **GAXPY** using nested `for` loops
- **GAXPY** with randomly generated matrices and vectors using `randi()`

The MATLAB programs are kept close to the classroom approach, using loops to understand the underlying operations rather than relying only on built-in matrix operations.
